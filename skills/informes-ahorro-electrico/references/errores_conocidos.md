# Errores conocidos y su corrección

| Error | Por qué pasa | Corrección |
|---|---|---|
| Potencias modificadas sin pedirlo | Se «optimiza» de más | Solo se tocan si el cliente lo pide; si no, se propone revisarlas aparte |
| Tolerancia del 5 % en excesos | Se aplica la regla antigua | Facturar todo exceso por encima de la potencia contratada |
| Descuento aplicado dos veces | Sumar un 15 % sobre un precio que ya lo incluye | Comprobar si el precio es final antes de descontar |
| Precios de una hoja caducada | Reutilizar el informe anterior | La hoja se sustituye entera y se recalcula |
| Argumento de «subida» sin datos | Falta de comparación | Diferencia de tarifas, con cifras y fechas |
| Pies de página ausentes | La página desborda a una segunda hoja | Compactar gráficos y tablas; nunca fijar altura de página |
| Ahorro fabricado | Presión comercial | Solo objetivos y escenarios condicionados |
| Autoconsumo comparado con precio de catálogo | Confundir catálogo con factura | Usar el precio acreditado en la factura del cliente |
| Reactiva recomendada con datos que discrepan | Factura y SIPS no coinciden | Resolver la discrepancia antes de recomendar compensación |
| Confundir NIF con autónomo | Atajo comercial | Documento del titular, no presunción |
| Escribir en el informe que el cliente no debe contratar | Se prioriza el análisis sobre la venta | El informe es captación: se cambia el marco, no los números; toda dificultad se convierte en palanca con acción de B&M |
