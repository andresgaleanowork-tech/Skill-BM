# Bandeja de presupuestos

Presupuestos ajenos o antiguos que hay que pasar a estilo B&M. No se suben al repositorio.

```bash
python tools/normalizar_documento.py bandeja/presupuestos/oferta_competencia.pdf
```

La reescritura la hace el asistente con la skill `presupuestos-bm`: nunca se copia tal cual.
